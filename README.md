# AWS Cloud Infrastructure Capstone

This repository contains hands-on AWS and DevOps projects built using Terraform, AWS CLI, Linux, and Git.

## Projects

| Project | Description | Technologies |
|---|---|---|
| 01 | EC2 Web Server | AWS EC2, Terraform |
| 02 | S3 Static Website | AWS S3, Terraform |
| 03 | EC2 CloudWatch Monitoring | EC2, CloudWatch, Terraform |
| 04 | IAM User Automation | AWS IAM, Terraform |
| 05 | Secure Linux Permissions | Linux, users, groups, permissions |
| 06 | Version Control Workflow | Git, GitHub, Pull Requests |

## Repository Structure

Each project has its own folder containing source files, documentation, and relevant screenshots.

## Note

Terraform state files, plan files, credentials, and local configuration files are excluded from version control.
